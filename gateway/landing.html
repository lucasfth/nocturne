Nocturne

A small LLM API served at night by a handful of idle Mac laptops. OpenAI-compatible. No account, no card: pay per request in sats over Lightning.

  • Open roughly 17:30–08:00 Europe/Copenhagen. Outside that, requests get 503 with Retry-After.
  • Small and experimental: a handful of Mac laptops, each running one or two requests at about 18–23 tokens/s. Machines drop out when in use or on low battery; the badge above shows how many are serving now. No uptime guarantee.
  • No prompts or outputs are logged. Only token counts per key are kept for billing.

API

GET  /v1/pricing             prices in msat and approx. DKK
POST /v1/keys                {} → new key (shown once)
POST /v1/credits/invoice     {"amount_msat":1000000} → bolt11
GET  /v1/credits/invoice/ID  paid / pending / expired
GET  /v1/credits/balance
GET  /openapi.json · /llms.txt
